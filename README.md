# Olist E-Commerce SQL Analysis

## Project Overview

This project analyzes the Brazilian Olist E-Commerce dataset using PostgreSQL.

The goal is to explore customer behavior, orders, revenue, products, sellers, reviews, and delivery performance using SQL.

## Tools Used

- PostgreSQL
- SQL
- GitHub

## Dataset

The project uses the **Brazilian E-Commerce Public Dataset by Olist**, which contains approximately 100,000 orders from an e-commerce platform in Brazil.

The dataset contains information about:

- Customers
- Orders
- Order Items
- Products
- Sellers
- Payments
- Reviews
- Geolocation

## Key Analysis Areas

The analysis covers questions related to:

### Orders
- Order trends over time
- Order status distribution
- Delivery performance
- Late deliveries

### Customers
- Number of unique customers
- Repeat customers
- Orders per customer
- Customer distribution by state

### Revenue & Products
- Total product revenue
- Revenue by product category
- Average order value
- Product sales

### Sellers
- Seller revenue
- Seller order volume
- Seller performance

### Reviews
- Review scores
- Customer satisfaction
- Relationship between delivery performance and reviews
